# Buildom

Reviving a 15-year-old game dream with modern AI workflows.

Buildom is a 2D block game I first built years ago as a classic two-man team. I was the designer, spending days and nights pixeling the world: every block, every item, every sprite hand-drawn. Back then, most of that work never made it past a static image. Life got in the way, and the project froze.

Now I'm rebuilding it from scratch, this time with modern AI workflows closing the gap between a nice picture and a living, interactive game. This repository is the open companion to that journey.

## What this repo is for

This is not the game source itself. It's the public home for everything around development:

- **Issues**: bug reports, ideas, and feature requests. If you spot something in a devlog post or a preview, open an issue.
- **Releases**: tagged milestones of the journey, each one tied to what's playable or demoable at that point.
- **Roadmap**: a rough plan of where the game is heading. Expect it to change, that's part of building in the open.

## The game

- A 2D pixel world rendered on canvas, with direct control over rendering, frames, and sprites.
- A modern web app around it, built with Next.js and React: menus, inventory overlays, settings, and editor panels as regular SPA UI.
- Local storage for permanent saves and world state, session storage for transient UI state.
- Multilingual from day one via `next-intl` (German and English).
